# Playwright Automation

A beginner-friendly repository covering Playwright fundamentals,
automation concepts, and practical examples using JavaScript and TypeScript.

## Tech Stack

- Playwright
- JavaScript
- TypeScript
- Node.js

## Concepts Covered

### Playwright Fundamentals
- Browser Launch
- Page Navigation
- Locators
- Assertions
- Screenshots
- Videos

### Browser Interactions
- Buttons
- Text Fields
- Dropdowns
- Checkboxes
- Radio Buttons

### Advanced Concepts
- Frames
- Multiple Windows
- Alerts
- Authentication
- Fixtures
- Page Object Model
